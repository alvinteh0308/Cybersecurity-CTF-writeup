# Cybersecurity CTF Writeups

Welcome to my Cybersecurity CTF Writeup Repository!

This repository documents my hands-on learning journey in cybersecurity through Capture The Flag (CTF) challenges, including picoCTF, TryHackMe and other cybersecurity learning platforms.

My goal is to strengthen my practical skills in **Digital Forensics, Web Exploitation, Reverse Engineering, Linux and Security Analysis**, while developing a systematic approach to investigating and solving cybersecurity challenges.

Each writeup includes the investigation process, commands used, findings and lessons learned.
